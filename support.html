Help & Technical Documentation

How Can We Help You?

Step-by-step documentation, printer setup guides, and troubleshooting for Taksal Studio v3.0.0.

1. High-Resolution 300 DPI Export Guide

To generate print-ready assets for professional physical printing:

  1. Open your design in the Canva Vector Editor.
  2. Tap the Export button on the top right app bar.
  3. Select High Quality (300 DPI) in the resolution picker dialog.
  4. Choose PDF for offset commercial printing or PNG with alpha transparency for digital sharing.
  5. Tap Save to Gallery or Share. The rendered file is securely compiled using iText7 and Skia.

2. Thermal POS Printer Setup (58mm / 80mm)

Connect your Android device to a retail counter thermal slip printer:

  1. Pair your thermal printer via Android Bluetooth settings or plug in via USB OTG.
  2. Install your printer manufacturer's Android Print Service plugin (e.g. RawBT or generic ESC/POS service).
  3. In Taksal Studio, navigate to Business Tools > Thermal Receipt Generator.
  4. Enter receipt items and customer details, then tap Print Receipt.
  5. Select 58mm or 80mm paper width and choose your connected printer.

3. Restoring Drafts from Trash Vault

Accidentally removed a business card or invoice draft? Taksal implements a safe soft-delete vault:

  1. Navigate to Settings > Trash & Version Vault.
  2. Browse your soft-deleted designs and documents.
  3. Tap Restore next to any item to return it immediately to your active projects runway.
  4. Items remain in the vault for 30 days before permanent deletion unless manually purged.

4. Gemini 3.5 AI Studio API Key Setup

To enable generative design prompts using your own Google AI Studio quota:

  1. Visit aistudio.google.com and create a free Gemini API key.
  2. In Taksal Studio, go to Settings > Gemini 3.5 AI Studio.
  3. Paste your key into the secure prompt and tap Save API Key.
  4. Your key is immediately encrypted at rest using Android KeyStore AES-256-GCM.

Temporary Cache vs. Project Database

If you ever need to free up device storage, open Settings > Storage, Security & Performance > Clear Temporary Cache.

Important Guarantee: Clearing cache removes only transient render bitmaps and temporary thumbnail cache. Your saved canvas designs, brand kits, invoices, product inventory, and customer databases are stored in the persistent SQLite database and are never deleted by clearing cache.
